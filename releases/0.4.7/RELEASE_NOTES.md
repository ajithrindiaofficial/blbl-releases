# blbl v0.4.7

Released: 2026-02-22

## blbl v0.4.7

Download the DMG file below to install blbl on macOS.

### Installation
1. Download the DMG file for your Mac
2. Open the DMG file
3. Drag blbl.app to your Applications folder
4. Launch blbl from Applications

### What's New

### Changed
- Removed iCloud/Cloud Backup UI and app command wiring from `blbl-app`
- Retained local backup/export and automatic local backup workflows
- Removed iCloud provisioning profile dependency from release workflow
- Removed macOS iCloud entitlements usage from Tauri bundle configuration
