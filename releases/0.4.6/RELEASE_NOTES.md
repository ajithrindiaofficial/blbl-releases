# blbl v0.4.6

Released: 2026-02-22

## blbl v0.4.6

Download the DMG file below to install blbl on macOS.

### Installation
1. Download the DMG file for your Mac
2. Open the DMG file
3. Drag blbl.app to your Applications folder
4. Launch blbl from Applications

### What's New

### Changed
- Hidden the Cloud Backup tab from the Settings sidebar to simplify the current test build UX.
- Added a safe fallback so invalid Settings deep-links now open the General section instead of a missing tab state.
