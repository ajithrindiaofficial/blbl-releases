# blbl v0.4.8

Released: 2026-03-17

## blbl v0.4.8

Download the DMG file below to install blbl on macOS.

### Installation
1. Download the DMG file for your Mac
2. Open the DMG file
3. Drag blbl.app to your Applications folder
4. Launch blbl from Applications

### What's New

### Fixed
- Reduced blocking license validation so reconnect and periodic checks no longer show the full-screen loading state when cached license data is still fresh
- Added cached license-state reuse and deduped overlapping license checks to avoid unnecessary validation churn during intermittent connectivity
